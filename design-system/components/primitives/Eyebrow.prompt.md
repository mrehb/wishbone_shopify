# Eyebrow

The only element set in DotGothic16. A 12px tracked upper-case label — `01  THE LINEUP` — above every section headline, with a 20px lime rule to its left on paper. On the ink band the text itself is lime and the rule is dropped. Never used for body, headings, prices or buttons; if the dot face appears anywhere else, it is a mistake.

Props: `n` (two-digit section number), children (the label).
