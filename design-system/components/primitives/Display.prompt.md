# Display

Every headline in the brand. Manrope 300, upper case, 2% tracking, line-height 1.08. Written as short statements, one per line, each ending in a full stop: `LIGHT.` / `SIMPLE.` / `BRITISH.` Three lines at most. Sizes: hero 56, display 40, s 28. Never bold, never a second typeface, never sentence case at these sizes.
