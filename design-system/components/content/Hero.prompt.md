# Hero

The homepage currently runs three sections and no hero — this is the opener it lacks.

Numbered label, product name, one sentence, one primary action, and a telemetry strip of up to four
values. The strip is the point: the first screen reports facts rather than making a claim, which is
the whole brand in one block.

The media slot takes a photograph **or** a dot-matrix silhouette. Use the silhouette when the page
is about the range or an idea, the photograph when it is about one object you want desired.
Never both, never a carousel.
