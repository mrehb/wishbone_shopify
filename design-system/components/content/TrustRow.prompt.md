# TrustRow

Three or four facts across the page, stated as values. **No icons, no badges, no ribbons** — a
brand that reports numbers does not need a shield graphic to be believed.

Use things that are true and checkable: parts listed, shipping origin, delivery window, warranty
length. *"22 · spare parts listed"* outperforms *"Trusted quality"* because a customer can verify it
in one click.

If a value is not yet decided — warranty length, for instance — leave the row out entirely rather
than writing something vague. An honest gap is fine; a soft claim is not.
