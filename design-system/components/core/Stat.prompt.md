# Stat

The page's basic unit in v2. A numbered mono label, one value in the telemetry face, and optional
supporting pairs — the layout the whole reference is built from.

Number panels in reading order (`01`, `02`, `03`) and keep the numbers stable across a page; they
are addresses, not decoration. Values are real measurements — range, price, part count, charge
time. **If a number is not known, print `—`.** Inventing a spec is the one thing that breaks a
brand built on numbers as proof.
