# Input

Square, transparent, 1px hairline at 55 % opacity. Label sits above the field in muted 12px —
placeholders are examples (*you@example.com*), never labels.

Error state turns the border `--color-error` **and** prints a sentence that says what to do:
*“Add the part after the @ — for example you@example.com.”* Never a red border alone, and never
just *“Invalid”*.
