# Input

Raised surface (`--surface-raised`), 10px radius, mono uppercase label above the field.
Placeholders are examples, never labels.

Errors turn the border `--color-error` **and** print a sentence that says what to do:
*“Add the part after the @ — for example you@example.com.”* Never a red border alone, never
just *Invalid*.

Changed in v2: transparent field → raised surface, radius 0 → 10px, sentence label → mono caps.
