# DotMatrix / DotBars

The signature device of the rebrand. Every quantity, silhouette, chart or progress state is drawn
as a grid of dots — white at 18–92 % opacity for the body of the data, volt for the part that
matters. It is what makes a Wishbone page read as an instrument rather than a shop.

Use it for: product silhouettes (generate the grid by sampling a photo's luminance), battery and
range readouts, the model range, spare-part availability, anything that reports a number.

Do not use it as texture or background pattern. A dot matrix always means *this is data*; the
moment it decorates, the device stops working. Keep dot size 5px / gap 3px unless the panel is
large — the grid should read as discrete points, never as a halftone image.
