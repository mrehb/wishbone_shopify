# ModelCompare

Five models is small enough to compare in one table, which is exactly why the store should — today
a customer has to open five tabs to work out whether they want TWO or THREE.

Mono values so the columns align without effort. A missing spec renders as a muted `—`, never a
blank cell and never an optimistic guess: the gaps are the argument for measuring fold size and
weight. The model being viewed is highlighted in volt, and it is the only volt on the row.

Rows worth carrying: type, price, wheels, frame, battery, range, fold size, weight, parts listed.
The last one is a genuine differentiator for this brand and nobody else publishes it.
