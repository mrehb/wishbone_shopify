# HeroTile

The first tile on any board, spanning it. Title at 96px dot-matrix with the blinking cursor, one
sentence, one lime action, up to four readouts, and the silhouette of the model on the right.

It is the same tile as every other — same radius, padding and label — just wider. There is no
separate hero treatment, no photography bleed, no gradient overlay. The lamp on the page is the
only atmosphere.
