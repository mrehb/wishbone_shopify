Sampled from the real photographs. These are what a colourway swatch is painted with and what the hardware is. None of them is ever an interface colour — no red button, no red error, no olive text.

The store photographs every product on white, so the site is white. One dark band per page at most, for the thing with the most technology in it. Lime is hue 70° — four degrees from the logo olive and four from the lime on the trolleys, so the mark and the interface are finally the same green. It appears once per view as the purchase, and as small marks: the eyebrow rule, the active slide, the selected tag. The interface has no red; an error is a lime line and a sentence.
